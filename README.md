# gophkeeper
Менеджер паролей GophKeeper


## Текущий статус

Сейчас проект находится на этапе формирования архитектурного каркаса.

Зафиксированы базовые решения:
- клиент-серверная архитектура;
- CLI-клиент;
- HTTP/JSON как транспорт первой версии;
- PostgreSQL как основное серверное хранилище;
- Dependency Injection как основной подход к организации зависимостей;
- сервер как источник истины;
- единая доменная сущность SecretItem для всех типов секретов.

Подробности находятся в каталоге `docs/`.

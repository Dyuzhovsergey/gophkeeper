# Черновик HTTP API

## Аутентификация

### POST /api/user/register
Регистрация пользователя.

### POST /api/user/login
Аутентификация пользователя.

## Работа с секретами

### GET /api/secrets
Получить список секретов текущего пользователя.

### GET /api/secrets/{id}
Получить один секрет текущего пользователя.

### POST /api/secrets
Создать новый секрет.

### PUT /api/secrets/{id}
Обновить секрет.

### DELETE /api/secrets/{id}
Удалить секрет.

## Синхронизация

### GET /api/sync
Получить актуальные изменения пользователя.

## Авторизация

Для защищённых запросов используется заголовок:

Authorization: Bearer <token>

## Общие правила

- transport DTO не должны совпадать с domain-моделями один в один автоматически;
- сервер обязан фильтровать данные по владельцу;
- ошибки должны быть приведены к единому формату на следующих этапах разработки.
